# Куда класть картинки

Игра работает и без картинок: если файла нет, объект рисуется кодом
(см. `js/assets.js`). Как только файл появится по нужному пути, он подхватится
автоматически. Менять код не нужно.

## Пути файлов

```
assets/birds/red.png        красная птица
assets/birds/yellow.png     жёлтая птица
assets/birds/blue.png       синяя птица
assets/birds/black.png      чёрная птица

assets/pigs/small.png       мелкая свинья
assets/pigs/normal.png      обычная свинья
assets/pigs/king.png        король в короне
assets/pigs/helmet.png      свинья в каске

assets/blocks/wood.png      деревянный блок
assets/blocks/stone.png     каменный блок
assets/blocks/ice.png       ледяной блок
assets/blocks/tnt.png       ящик динамита

assets/slingshot.png        рогатка
assets/background.png       фон
```

Если имена твоих файлов другие, не переименовывай их: поправь пути в объекте
`manifest` в начале `js/assets.js`. Это единственное место, где пути прописаны.

## Требования к картинкам

- **Формат:** PNG с прозрачным фоном. JPEG не подойдёт, у него нет прозрачности,
  и вокруг птицы будет белый квадрат.
- **Птицы и свиньи:** квадратные, персонаж вписан в квадрат и смотрит вправо.
  Игра поворачивает спрайт вместе с физическим телом, поэтому центр картинки
  должен совпадать с центром персонажа, иначе он будет вращаться «вокруг уха».
- **Блоки:** картинка растягивается под размер блока. Лучше всего подходит
  текстура, которая нормально выглядит при растягивании.
- **Размер:** примерно 128×128 пикселей достаточно. Очень большие файлы
  замедлят загрузку без видимой пользы.

## Как проверить, что подхватилось

Открой консоль браузера (F12). При запуске игра пишет список ненайденных
файлов. Пустой список означает, что все картинки на месте.
