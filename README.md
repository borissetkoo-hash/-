# Cartman's Water

Браузерный клон *Where's My Water?*: копайте землю, чтобы провести синюю воду
в рот Картману и фиолетовую (как в оригинальной игре) — в стеклянную чашу.
Жидкость симулируется посимвольной сеточной физикой (falling-sand automaton),
как в оригинале: течёт вниз, растекается в стороны, ищет путь наименьшего
сопротивления.

Открыть `index.html` в браузере (или поднять любой статический сервер в
корне репозитория) — сборка не требуется.

- `index.html` — разметка и HUD
- `css/style.css` — оформление
- `js/game.js` — уровень, физика воды, копание, подсчёт очков
- `assets/cartman.jpg` — спрайт персонажа
